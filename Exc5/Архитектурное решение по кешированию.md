## Анализ диаграммы системы и её описания

Имеет смысл закешировать используемые в системе базы данных - ShopDB и MES DB. 
Кэшировать что-то еще имеет смысл после анализа статистики по логам. 

## Мотивация

1. Исполнение требований к системе
2. Ускорение работы системы
3. Исключение проблемы потери заказов

## Предлагаемое решение

Внедрить серверное кеширование — исходя из анализа системы.

### ShopDB

Основные используемые данные:

1. Список товаров - много чтений, мало записей
2. Список заказов - много чтений, много записей
3. Список клиентов - много чтений, мало записей

Для получения списка товаров и клиентов применить паттерн cache-Aside с инвалидацией по времени, 
т.к. он простой и не накладывает особых требований на отказоустойчивость кэша.

Для получения списка заказов  - Write-Through, т.к. требуется актуальное состояние заказа как для клиента, так и для Продавца.

Минусы Refresh-ahead: 
Кеш должен работать без ошибок, поскольку в случае ошибки это будет не сразу определено и приведёт к неконсистентности данных и чтению из базы. 

### MES db

Основные используемые данные:

1. Список заказов - много чтений, много записей
2. Назначение заказа на оператора - много чтений, много записей
3. Статусы заказов - много чтений, много записей

Здесь применяем Write-Through, т.к. требуется актуальное состояние заказа.

**Сравнительный анализ стратегий инвалидации**

|    Данные      |         Программная        |          По ключу                   |         На запросах              |      На изменениях       | Временная |
|----------------|----------------------------|-------------------------------------|----------------------------------|--------------------------|-----------|
|    Товары      |Возможно                    |Лучше - точно знаем, что обновляется |Не зависит от активности клиентов |Приемлемо                 |    -      |
|    Клиенты     |Лучше - по смене состояния  |                                     |                                  |                          |    -      |
|    Заказы      |Лучше - по смене статуса    |Приемлемо                            |Возможно                          |Возможно                  |    -      |
